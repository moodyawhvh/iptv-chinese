## 📖 项目简介

iptv-org/iptv 收集了全世界公开可用的 IPTV(网络协议电视)直播频道,并自动整理成标准 m3u 播放列表。频道可按国家、语言、类别、地区多维筛选,把列表链接粘贴到任意支持直播流的播放器(如 VLC)即可观看。本仓库是其官方 README 的中文翻译版本,附中文使用教程与常用订阅链接速查。

## ✨ 主要特性

- 🌍 **全球频道收录**:汇聚来自世界各地公开可用的 IPTV 直播频道。
- 🔄 **持续自动更新**:通过 GitHub Actions 定时构建,播放列表保持最新。
- 📺 **一行订阅**:主播放列表一个链接,收录仓库内全部可用频道。
- 🗺️ **多维分类**:播放列表按国家、语言、类别、地区四种维度拆分,按需取用。
- 🗓️ **配套 EPG**:iptv-org/epg 项目提供大部分频道的电子节目指南。
- 🗄️ **独立数据库**:频道元数据维护在 iptv-org/database,持续校对。
- 🔌 **公开 API**:iptv-org/api 提供查询接口,方便二次开发。
- ⚖️ **CC0 许可**:仓库不存储任何视频文件,仅收录公开链接。

## 🚀 快速开始

**1. 复制主播放列表链接(包含全部频道):**

```
https://iptv-org.github.io/iptv/index.m3u
```

**2. 在 VLC 等播放器中打开「网络串流」,粘贴链接并播放。**

**3. 按国家订阅(示例为中国频道):**

```
https://iptv-org.github.io/iptv/countries/cn.m3u
```

**4. 按语言订阅(示例为中文频道):**

```
https://iptv-org.github.io/iptv/languages/zho.m3u
```

**5. 更多按类别、地区划分的播放列表,请见原仓库 PLAYLISTS.md 文件。**

**6. 需要节目单可搭配 EPG 使用:**

```
https://iptv-org.github.io/epg/index.xml.gz
```
